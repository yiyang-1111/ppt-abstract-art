# ppt-abstract-art

用抽象艺术插图搭配学术导读版式制作 PPT 的 Skill 模板。

## 内容

- `SKILL.md` — 完整设计规范与使用流程
- `assets/ppt 模板.pptx` — 原始 PPT 模板文件
- `assets/抽象艺术插图/` — 12 张抽象艺术画素材（横版/竖版/方图）

## 适用场景

学术论文读书会、文献导读、研究报告讲解——每页配一张抽象艺术画作为视觉锚点，配色取自插图，字体统一衬线宋体，版式克制留白。

## 快速开始

1. 读取 `SKILL.md` 了解页面结构模板与配色规范
2. 从 `assets/抽象艺术插图/` 中按版式需要挑选配图
3. 按 `SKILL.md` 中的页面结构逐页填充内容
